# ASCP・資格・用語まとめ（米国の臨床検査技師の「現場の声」を読むために）

作成: 2026-10-03。きっかけは r/medlabprofessionals の「I just passed the (C) ASCP!!!」（現場の声の候補）。
投稿の中に出てくる ASCP・Cレベル・資格の種類・固有名詞が、日本の読者にはわかりにくいと感じたため。

**信頼度の見方**: ✅=ASCP等の公式情報または複数の情報源で確認 / 🟡=第三者サイト1つのみ（要確認）/ ❓=確認できず（推定を明記）。
ASCP公式の資格要件PDF（BOC Procedures Book）は取得時に403で読めなかったため、受験ルートなど細部は 🟡 のものがある。**公式ページで最終確認してから使うこと**。

## 1. 先に結論

- **「Cレベル」という等級はない。** `C(ASCP)` の `C` は **Chemistry（臨床化学）** の頭文字で、分野を表す。✅
- **ASCP は国家資格ではなく、米国の学会（American Society for Clinical Pathology）が運営する民間の認定資格。** ✅
  日本の臨床検査技師のような「国が一括で出す免許」は米国にはなく、**州の免許（州ごとに要否が違う）＋民間の認定資格**の二重構造になっている。
- 投稿者が「Cを選んだ理由」を聞かれて「micro（微生物）の資格は経験の条件で受けられなかった」と答えているのは、**分野別資格は受験に“その分野での実務経験”が要る**ため（4章）。
- **放射線技師（Rad Tech）は別の資格・別の学校。** MLT/MLSから自動的になれる道はない（7章）。

## 2. 米国の「資格のレイヤー」

| 層 | 何を決めるか | 例 |
|---|---|---|
| ① 学歴・養成課程 | 準学士（2年）か学士（4年）か、認定された課程か | NAACLS認定のMLS/MLTプログラム 🟡 |
| ② 民間の認定資格 | 試験に合格して名乗れる肩書き | ASCP BOC の MLS(ASCP)、MLT(ASCP)、C(ASCP) など ✅ |
| ③ 州の免許 | 働くのに必要かどうか（州による） | CA・NYは独自の州試験あり 🟡 |

**州免許が必要な州（調査時点）**: CA, FL, HI, GA, LA, MT, NV, NY, ND, TN, WV, プエルトリコ 🟡（第三者の一覧）。それ以外の多くの州は免許不要で、ASCP等の認定が雇用の実質的な条件になる。**州ごとに変わるので、特定の州の話をするときは必ず州の公式情報を確認すること。**

投稿に「フロリダは免許の要件が緩和された」という書き込みがあったが、これは投稿者の発言で、こちらでは裏取りしていない ❓。

## 3. ASCP と BOC

- **ASCP** = American Society for Clinical Pathology（米国臨床病理学会）。✅
- **BOC** = Board of Certification（認定委員会）。ASCPの中で資格試験・認定を担う部門。投稿の「BOC exam」「BOC questions」は、この試験・問題集のこと。✅
- 認定は3年ごとの更新制。資格名の末尾に付く **`CM`**（例: `C(ASCP)CM`）は、更新プログラム（Credential Maintenance Program）に参加していることを示す。✅
  → 投稿の `(C) ASCP` と `C(ASCP)` は同じもの。表記ゆれ。

## 4. 資格の種類（略号の読み方）

ASCP BOC の資格は、段階（レベル）で4つに分かれる 🟡:

**① Medical Laboratory Scientist（検査の“科学者”）**
- `MLS(ASCP)` … 学士レベルで、全分野（generalist）を扱える。投稿の「MLS-Generalist」はこれ。

**② Technician（技術員。準学士レベルが中心）**
- `MLT(ASCP)` … Medical Laboratory Technician。
- `PBT(ASCP)` … Phlebotomy Technician（採血専門）。
- `HT(ASCP)` … Histotechnician（組織標本）。
- `MLA(ASCP)` … Medical Laboratory Assistant。

**③ Technologist（分野別の技術者。「categorical」と呼ばれる）**
- `C` … Chemistry（臨床化学）
- `H` … Hematology（血液学）
- `M` … Microbiology（微生物学）
- `BB` … Blood Banking（輸血・血液銀行）
- `MB` … Molecular Biology（分子生物学）
- `CG` … Cytogenetics（細胞遺伝）、`CT` … Cytology（細胞診）、`HTL` … Histotechnologist（組織技術者）

**④ Specialist（より専門的。実務経験や学位がさらに要る）**
- `SC` / `SH` / `SM` / `SBB` / `SMB` … 上の分野の「S」付き版。**`SBB(ASCP)` = Specialist in Blood Banking**。
  投稿の「SBBを取りたいが価値がない気がする」はこれ。輸血分野の上級資格。

**公式の表現**: BOCは、より複雑な知識体系で2〜3年の実務経験や学位・資格を要するものを “specialty（専門）” と位置づけている ✅。

### 「categorical」ってなに？
MLS（全分野）と違い、**1つの分野だけの資格**。投稿者は病院で化学と微生物を2.5年担当し、**化学のC**を取った。
MLSの学位がなくても、**その分野の経験があれば受けられるルート**があるのが特徴。

## 5. 受験資格ルート（C(ASCP) を例に）🟡

第三者サイトの要約（公式で要確認）:

- Route 1: MLS(ASCP) 保持＋学士号
- Route 2: **化学または生物科学の学士号＋過去5年以内に化学分野で1年間のフルタイム実務経験**
- Route 3: 学士号＋NAACLS認定のMLS課程内の化学の修了（5年以内）
- Route 4: 化学等の修士号＋化学分野で6か月のフルタイム実務（5年以内）
- Route 5: MLSの学士号＋NAACLS認定課程の修了（5年以内）
- 実務経験の要件: 過去5年以内に、血液ガス・糖・電解質・電気泳動・酵素・ホルモン・脂質など**15項目中8項目**の経験

→ 投稿者の場合、化学の経験は満たしたが、勤務先のmicroは規模が小さく検体の多くを外注していたので、**micro(M)の受験に必要な項目数を満たせなかった**と読める（本人の説明からの推測）。

## 6. 試験の仕組み

- **CAT（コンピュータ適応型テスト）**: 正誤に応じて次の問題の難しさが変わる。ASCP BOC の多くの試験で採用 ✅。
- **MLS: 100問・2.5時間**、スコアは **100〜999、合格は400以上** ✅（分野別試験の問題数・時間は未確認 ❓）。
- 投稿者は「試験は最悪の感触で、半分は知らない問題か推測だった。それでも合格した」と書き、返信した別の合格者も「同じで、落ちたと思ったが受かった」と書いている。
  → CATは受験者の実力付近の難しさに収束するように設計されるため、手応えが悪く感じやすい、と言われる（一般的な説明で、こちらでは裏取りしていない ❓）。
- 勉強期間: 投稿者は約3か月、平日1日2〜5時間（フルタイム勤務なしの条件）。

## 7. 放射線技師（Rad Tech）との関係

- **MLT/MLS と Rad Tech は別の職種。** Rad Tech は ARRT（American Registry of Radiologic Technologists）の認定で、JRCERT認定のラジオグラフィ課程を修了する必要がある 🟡。
- 検索では「MLTからRad Techへ転換できる」「単位が認められる」という公式情報は**見つからなかった** ❓。進むなら新たに養成課程に入るのが基本、と見るのが安全。
- 投稿「MLT vs RAD tech」の内容（体験談で、公式ではない）:
  - Rad Techの夫を持つMLTが「やり直せるならRad Techを選ぶ。学校は同じ年数で、給与が高い」と回答。
  - MRI/CTでは $40/時以上、10年以上で $50/時くらい、という書き込み。
  - 患者との接触は多い（ED・入院で1日20人前後など）。人見知りの人には負担、という声。
  - **ラボとX線の両方を担う技師（combined lab and X-ray tech）もいるが、ニッチで地方向け**、という書き込み。
  - 投稿者の質問者は「MLTプログラム在学中に迷っている」状態で、MLS課程を中退してRad Techに移った人もいる。
- 日本では**臨床検査技師と診療放射線技師は別々の国家資格**で、MRIや超音波検査はどちらも実施が認められている（教育課程の時間数は診療放射線技師の方が長い、という研究がある）🟡。

## 9. 日本との対応（ざっくり）

| 日本 | 米国 |
|---|---|
| 臨床検査技師（国家資格・1つ） | MLT / MLS / 分野別(C,H,M,BB…) / 専門(SC…)＋州免許 |
| 養成: 専門学校〜大学 | MLT=準学士(2年)、MLS=学士(4年) |
| 国が免許を管理 | 民間(ASCP等)が認定、州が免許を管理（州により不要） |

**1対1では対応しない。** 「日本の臨床検査技師 ≒ MLS」とは言い切れないので、サイト上では断定せず「おおむね」と書く。
